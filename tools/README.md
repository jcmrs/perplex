# Automation Tools Directory

**Purpose:** Scripts and utilities for common operations and AI agent autonomy.

## Principles

- **Automation Cornerstone:** Manual processes are temporary
- **Self-Service:** AI agents can execute without human intervention
- **Idempotent:** Safe to run multiple times
- **Documented:** Each script has clear purpose and usage

## Standard Tools

- `session-start.sh` - Initialize new AI agent session
- `session-end.sh` - Finalize and commit session work
- `validate-foundation.sh` - Check alignment with foundation imperatives
- `generate-status.sh` - Update CURRENT_STATUS.md

## For AI Agents

Use these tools liberally. If you find yourself doing something manually twice, script it.

## For Humans

Run these scripts to perform project operations consistently.
